# Spendenziel verwalten
{: .no_toc }

---

{: .intern-title }
> ☠️ Admin-Bereich ☠️
>
> Diese Seite ist für die System-Admins.

Hier konfigurierst du die Spendenziele, die auf der [Spendenseite]({% link docs/event/donations.md %}) angezeigt werden. Jedes Spendenziel wird als eigener Abschnitt dargestellt.
{::comment}[[donations]]{:/comment}

![Spendenziele verwalten](/docs/admin/images/donation_goals.png)
## Felder pro Abschnitt

- **Bezeichnung**: Name des Spendenziels (z.B. «Server und Betrieb», «Vereinskosten»)
- **Zielbetrag (CHF):** der angestrebte Betrag
- **Reihenfolge:** bestimmt die Anzeigereihenfolge auf der Spendenseite
- **Jahr:** für welches Jahr das Spendenziel gilt
- **Details:** kurze Beschreibung, wofür die Spende verwendet wird

## Abschnitte verwalten

- **Neuen Abschnitt hinzufügen:** Klicke auf `Abschnitt hinzufügen`, um ein weiteres Spendenziel zu erfassen.
- **Speichern:** Klicke auf `Speichern` beim jeweiligen Abschnitt, um die Änderungen zu übernehmen.
- **Löschen:** Über das Löschen-Icon (Mülleimer) rechts oben im Abschnitt kannst du ein Spendenziel entfernen.
