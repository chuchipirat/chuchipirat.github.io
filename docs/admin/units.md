# Einheiten
{: .no_toc }

---

{: .intern-title }
> ☠️ Admin-Bereich ☠️
>
> Diese Seite ist für die Community-Leader\*innen und System-Admins.

Diese Seite dient der Verwaltung aller Einheiten, die im chuchipirat verwendet werden. Über den Button `Anpassen` kannst du die Einheiten bearbeiten.

Die Tabelle enthält folgende Spalten:

- **Einheit:** die gebräuchliche Abkürzung (z.B. EL, g, dl)
- **Name:** die vollständige Bezeichnung (z.B. Esslöffel, Gramm, Deziliter)
- **Dimension:** bestimmt, welche Einheiten untereinander umgerechnet werden können. Eine Umrechnung ist nur innerhalb derselben Dimension möglich. Die drei Dimensionen sind:
  - **Dimensionslos (DLS):** z.B. Blatt, Bund, Prise, Würfel
  - **Masse (MAS):** z.B. g, kg
  - **Volumen (VOL):** z.B. ml, cl, dl, l, EL, TL
