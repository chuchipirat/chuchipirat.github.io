# Spendenübersicht
{: .no_toc }

---

{: .intern-title }
> ☠️ Admin-Bereich ☠️
>
> Diese Seite ist für die Community-Leader\*innen und System-Admins.

Die Spendenübersicht zeigt alle Spendentransaktionen: sowohl erfolgreiche als auch fehlgeschlagene. Zuoberst siehst du drei Kennzahlen:

- **Total dieses Jahr**: Gesamtbetrag aller bestätigten Spenden im laufenden Jahr
- **Eindeutige Spender\*innen:** Anzahl verschiedener Personen, die gespendet haben
- **∅ Spende:** durchschnittlicher Spendenbetrag

![Spenenübersicht](/docs/admin/images/donations.png)
## Tabelle

Die Tabelle listet alle Transaktionen mit folgenden Spalten:

- **Datum:** Zeitpunkt der Transaktion
- **Betrag:** Spendenbetrag in CHF
- **Status:** `confirmed` (erfolgreich), `failed` (fehlgeschlagen) oder `migrated` (aus einem früheren System übernommen)
- **Zahlungsmethode:** z.B. Twint, Visa
- **Spender\*in:** Name der spendenden Person
- **Anlass:** der Anlass, über den die Spende ausgelöst wurde
- **Quittungsnummer:** eindeutige Belegnummer
- **Nachricht:** optionale Nachricht der spendenden Person

Über die Toolbar kannst du die angezeigten **Spalten** anpassen, die Tabelle **filtern**, die **Zeilenhöhe** ändern und die Daten **exportieren**.
