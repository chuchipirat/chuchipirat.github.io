# Rezept drucken
{: .no_toc }

---

Über den Button `Druckversion` kannst du ein Rezept als PDF herunterladen. Das PDF enthält alle Informationen, die du für die Zubereitung benötigst:

- Rezeptname
- Allgemeine Infos (Quelle, Portionen, Vorbereitung, Koch/Backzeit, Ruhezeit)
- Zutaten und Zubereitung
- Hinweis (falls vorhanden)
![Rezept Druckversion](/docs/recipe/images/recipe_print_version.png)

## Skalierte Werte

Hast du das Rezept vor dem Export skaliert, werden die angepassten Mengen auch in der Druckversion übernommen.

## Mehrere Rezepte exportieren

Willst du alle Rezepte eines Anlasses auf einmal exportieren, nutze die Funktion [Verwendete Rezepte]({% link docs/event/used_recipes.md %}) im Menüplan.
