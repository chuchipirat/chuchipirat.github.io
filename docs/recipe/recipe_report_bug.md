# Rezept Fehler melden
{: .no_toc }

---

Fehler können passieren, auch in öffentlichen Rezepten. Wenn du einen Fehler entdeckst, kannst du ihn der Community melden. Dein Hinweis wird von den Community-Leadern überprüft und das Rezept gegebenenfalls angepasst.

{: .note-title }
> Warum kann ich das Rezept nicht selbst anpassen?
>
> Öffentliche Rezepte können standardmässig nicht bearbeitet werden. So ist sichergestellt, dass alle mit demselben Rezept arbeiten. Stell dir vor, du hast ein Rezept für dein Lager geplant und jemand ändert die Zusammensetzung — das würde für alle Anlässe gelten. Um solche Überraschungen zu vermeiden, können öffentliche Rezepte nur von Community-Leadern korrigiert werden.

## Fehler melden

1. Öffne das Rezept über die [Rezeptübersicht]({% link docs/recipe/recipes_overview.md %}).
{::comment}[[recipes_overview]]{:/comment}
2. Klicke auf den Button `Fehler melden`.
3. Beschreibe möglichst genau, was im Rezept falsch ist.
4. Klicke auf `Fehler melden`, um die Meldung abzuschicken.

Die Community-Leader überprüfen deine Meldung. Wird der Fehler anerkannt, wird das Rezept korrigiert und dein Antrag als «erledigt» markiert. Falls Fragen auftauchen, meldet sich die prüfende Person per E-Mail bei dir.

Den aktuellen Status deiner Meldung kannst du jederzeit in deinen [Anträgen]({% link docs/request/requests.md %}) einsehen.
{::comment}[[requests]]{:/comment}
